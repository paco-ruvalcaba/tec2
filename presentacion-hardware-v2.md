# ¿Qué es el Hardware?

* Es todo el soporte físico y tangible de un sistema informático [2].
* A diferencia del software (programas y aplicaciones), el hardware se puede tocar, conectar y manipular físicamente [2].
* Su correcto uso y mantenimiento es indispensable para el desarrollo profesional y personal de los estudiantes [1].

# Módulo 1: Componentes Internos
### La Tarjeta Madre (Motherboard)

* **¿Qué es?** Es el circuito principal donde se conectan, alimentan y comunican todas las piezas del computador.
* **Factores de Forma (Formas y Tamaños comunes):**
  * **ATX (305 x 244 mm):** El tamaño estándar más común. Ofrece la mayor capacidad de expansión con 4 ranuras RAM, múltiples puertos PCIe (para tarjetas de video) y conectores de almacenamiento.
  * **Micro-ATX (mATX):** Un formato mediano y más económico. Tiene menos ranuras de expansión pero mantiene las prestaciones necesarias para el usuario común.
  * **Mini-ITX:** Formato ultracompacto para gabinetes pequeños. Es más costoso de fabricar y generalmente se limita a 2 ranuras RAM y una sola ranura PCIe.

# Módulo 1: El Microprocesador (CPU)
### El Cerebro de la Computadora

* **¿Qué es?** Ejecuta todas las instrucciones de los programas y coordina las tareas de los demás componentes.
* **Conceptos clave:**
  * **Frecuencia (GHz):** La velocidad con la que procesa los datos.
  * **Núcleos (Cores):** Subprocesadores físicos. A más núcleos, más tareas simultáneas reales se pueden realizar.
  * **Hilos (Threads):** Conductos virtuales que ayudan a organizar la cola de instrucciones.
* **Gamas de Procesadores (Intel Core vs. AMD Ryzen):**
  * **Básica (i3 / Ryzen 3):** Ideal para ofimática de oficina (Office), navegación web y tareas cotidianas escolares.
  * **Intermedia (i5 / Ryzen 5):** Equilibrio potencia/precio. Diseñado para multitarea fluida, estudios y juegos moderados.
  * **Avanzada (i7 e i9 / Ryzen 7 y 9):** Alto rendimiento para diseño profesional, edición de video 4K, modelado 3D y bases de datos masivas.

# Módulo 1: Memoria RAM
### El Espacio de Trabajo Temporal

* **¿Qué es?** Almacena de forma temporal y ultrarrápida los datos que el procesador necesita en tiempo real (aplicaciones abiertas, pestañas del navegador). Se vacía al apagar el equipo.
* **Comparativa Generacional (La evolución tecnológica):**
  * **DDR4:** El estándar consolidado desde 2014. Funciona a velocidades de 2133 a 3200 MT/s con un consumo de 1.2V. Es económica y muy compatible con equipos estándar actuales.
  * **DDR5:** La última generación. Duplica la velocidad alcanzando de 4800 a 8400+ MT/s, consume menos energía (1.1V) lo que genera menos calor, y tiene corrección de errores integrada (ECC) física para mayor estabilidad del sistema.

# Módulo 1: Almacenamiento Interno
### ¿Dónde se guardan los datos permanentemente?

A diferencia de la RAM, el almacenamiento guarda el sistema operativo y tus archivos de forma permanente.
* **HDD (Disco Duro Mecánico):** 
  * Almacenamiento tradicional magnético con discos giratorios físicos. Muy lentos (~150 MB/s), ruidosos y sensibles a golpes, pero económicos para guardar grandes cantidades de datos.
* **SSD SATA (Unidades de Estado Sólido de 2.5" o M.2 SATA):**
  * Usan memoria flash sin partes móviles. Son silenciosos y mucho más rápidos que un HDD (hasta ~550 MB/s). Ideal para revivir computadoras lentas de forma económica.
* **SSD NVMe (M.2 PCIe):**
  * El rey del rendimiento moderno. Se conecta directamente a la tarjeta madre usando el bus PCIe ultrarrápido y habla directamente con el procesador. Supera velocidades de 3500 MB/s hasta 7000+ MB/s. Crucial para cargas de programas instantáneas y edición profesional.

# Módulo 2: Puertos y Conectores
### ¿Cómo se comunican los dispositivos?

Para interactuar de forma segura con los equipos de cómputo, es vital identificar los conectores correctos:

* **Puertos USB (Tipo A y Tipo C):** Conectores universales para transferencia de datos y energía (memorias flash, teclados, mouse).
* **Puertos de Video (HDMI / DisplayPort / VGA):** Conectores para proyectar información en monitores, proyectores o pantallas secundarias.
* **Jack de Audio:** Conectores de 3.5mm para auriculares y micrófonos externos.
* **Regla de oro:** Nunca forzar una conexión física para evitar daños irreversibles en el hardware.

# Módulo 3: Hardware de Red y Conectividad
### El Puente para Acceder a la Información

Para realizar búsquedas eficaces en bases de datos científicas o interactuar en redes sociales educativas, necesitamos conectar físicamente el hardware al mundo [1, 2]:

* **Tarjeta de Red (NIC):** Componente interno que permite la conexión física (vía cable) o inalámbrica (Wi-Fi).
* **Cable Ethernet (RJ-45):** El medio de conexión física más veloz y estable para el laboratorio de cómputo [3].
* **Módem / Router:** Dispositivos de red externos que reciben, traducen y distribuyen la señal de internet hacia nuestros equipos.

# Módulo 5: Ergonomía y Cuidado Físico del Equipo

* **Ergonomía Computacional:**
  * Mantener la espalda recta apoyada en el respaldo.
  * Mantener la pantalla a la altura de los ojos (distancia de 50-60 cm).
  * Posición neutra de las muñecas al teclear.
* **Cuidado del Hardware en el Laboratorio:**
  * No consumir alimentos ni bebidas cerca de los equipos.
  * Limpieza segura con paños de microfibra y sin aplicar líquidos directamente a las pantallas.
