# ¿Qué es el Hardware?

* Es todo el soporte físico y tangible de un sistema informático.
* A diferencia del software (programas y aplicaciones), el hardware se puede tocar, conectar y manipular físicamente.
* Su correcto uso y mantenimiento es indispensable para el desarrollo profesional y personal de los estudiantes.

---

# Módulo 1: Componentes Internos
### El "Cerebro" y el Soporte de la Computadora

1. **Tarjeta Madre (Placa Base):** El circuito principal donde se conectan y comunican todas las piezas.
2. **Microprocesador (CPU):** El cerebro que procesa todas las instrucciones del sistema.
3. **Memoria RAM:** Memoria de acceso rápido y temporal que el procesador usa para ejecutar tareas activas.
4. **Unidad de Almacenamiento (HDD/SSD):** El disco donde se guardan permanentemente los datos, sistemas operativos y archivos.
5. **Fuente de Poder:** Transforma y distribuye la energía eléctrica adecuada a cada componente físico.

---

# Módulo 2: Puertos y Conectores
### ¿Cómo se comunican los dispositivos?

Para interactuar de forma segura con los equipos de cómputo, es vital identificar los conectores correctos:

* **Puertos USB (Tipo A y Tipo C):** Conectores universales para transferencia de datos y energía (memorias flash, teclados, mouse).
* **Puertos de Video (HDMI / DisplayPort / VGA):** Conectores para proyectar información en monitores, proyectores o pantallas secundarias.
* **Jack de Audio:** Conectores de 3.5mm para auriculares y micrófonos externos.
* **Regla de oro:** Nunca forzar una conexión física para evitar daños irreversibles en el hardware.

---

# Módulo 3: Hardware de Red y Conectividad
### El Puente para Acceder a la Información

Para realizar búsquedas eficaces en bases de datos científicas o interactuar en redes sociales educativas, necesitamos conectar físicamente el hardware al mundo:

* **Tarjeta de Red (NIC):** Componente interno que permite la conexión física (vía cable) o inalámbrica (Wi-Fi).
* **Cable Ethernet (RJ-45):** El medio de conexión física más veloz y estable para el laboratorio de cómputo.
* **Módem / Router:** Dispositivos de red externos que reciben, traducen y distribuyen la señal de internet hacia nuestros equipos.

# Módulo 4: Periféricos de Entrada y Salida
### Interactuando con la Información

* **Dispositivos de Entrada (Introducen datos):**
  * Teclado, mouse, cámaras web (clave para telemedicina y videollamadas) y micrófonos.
* **Dispositivos de Salida (Muestran resultados):**
  * Monitor (pantalla), impresoras y proyectores para exposiciones en clase.
* **Dispositivos de Almacenamiento Externo:**
  * Discos duros portátiles y memorias USB para respaldar y transportar proyectos de cómputo de forma segura.

---

# Módulo 5: Ergonomía y Cuidado Física del Equipo

* **Ergonomía Computacional:**
  * Mantener la espalda recta apoyada en el respaldo.
  * Mantener la pantalla a la altura de los ojos (distancia de 50-60 cm).
  * Posición neutra de las muñecas al teclear.
* **Cuidado del Hardware en el Laboratorio:**
  * No consumir alimentos ni bebidas cerca de los equipos.
  * Limpieza segura con paños de microfibra y sin aplicar líquidos directamente a las pantallas.
